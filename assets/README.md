# Assets

- `brand/logo.png`: the 2026 Evolution Golf logo from evolutiongolf.co.uk (white with yellow "GOLF").
- `brand/clubhouse-seal-white.png`: the Clubhouse seal from the sign-up page brand pack, used on the video end card.
- `video/studio-mat.jpg`, `video/studio-lights.jpg`: frames from Evo's own studio reels. AI clips use them as the setting
  reference so every video is shot "in" the Evo studio.

Fonts (Inter) are fetched from Google Fonts at render time and cached; they aren't stored here.
